# TWRP for Moto G54 Cancunf (Motorola)

This repository is an ongoing attempt to build TWRP (Team Win Recovery Project) for the Moto G54 Cancunf (Motorola). This is an **UNOFFICIAL** build and is a **Work In Progress** (WIP). It is not fully functional and should be used with caution.

## Device: Moto G54 Cancunf
- **Manufacturer**: Motorola
- **Codename**: cancunf
- **Chipset**: MediaTek Dimensity 7020
- **Architecture**: ARM64

## Status
- **WIP**: The recovery is still being developed and is not ready for daily use.
- **Currently working on**: Custom kernel, boot image, device tree, and vendor setup.

## Disclaimer

This recovery is based on TWRP, an open-source project developed by the Team Win Recovery Project.  
All custom modifications to the TWRP source code are done at the user's own risk.  
This is a **UNOFFICIAL** build and **work in progress**, and should not be used on a production device. Proceed with caution.
